Privacy Policy

This policy explains how Bound handles information when you use the Bound Discord application website dashboard support systems and private server features

Effective 23 August 2026

Privacy at a glance

We collect only the data needed to provide operate secure and improve Bound We use it for requested features server administration abuse prevention support and legal compliance We do not sell personal data

1 Who operates Bound

Bound is operated by the Bound team through Bound Society This policy applies to the Bound Discord application the website at bound.center the dashboard and connected services

Questions access requests and deletion requests can be sent to goatedkillr@gmail.com or submitted through the Bound Society support server

2 Information we process

Discord account and server data

We may process Discord user server role channel message interaction permission and application command identifiers Display names avatars and server names may be shown in the bot or dashboard We receive only the Discord OAuth scopes shown during sign in including identify and guilds when you use the dashboard

Feature data

Depending on the features used we may store profiles preferences consent choices blocks relationships economy balances achievements command settings tickets verification status moderation and safety records staff activity audit events subscription entitlements and configured messages or channels

Messages and content

Bound processes command inputs button selections modal responses and content needed for enabled features Some server owners may enable logs tickets transcripts welcome messages global chat moderation or safety tools The bot does not need to permanently store every Discord message and stores feature content only where required by the selected system

Website and technical data

The website may process Discord login sessions authorised servers permissions IP address request metadata device or browser information security logs and the settings you save The dashboard stores its login session in your browser so you remain signed in

3 Why we use information

  • Provide commands profiles relationships economy roleplay tickets verification moderation and private server systems
  • Authenticate users and confirm current Discord server permissions
  • Let authorised server managers enable disable and configure commands and features
  • Apply consent blocks privacy choices safewords and other safety controls
  • Investigate abuse respond to reports enforce rules prevent fraud and preserve service integrity
  • Operate subscriptions support troubleshoot failures and improve reliability
  • Meet legal obligations and protect users Bound Discord and the public

4 Website command controls

Authorised server managers can use the dashboard to enable disable or configure available commands and systems for their server Changes are tied to the selected Discord server and are permission checked Disabling a command stops future use where supported but does not automatically erase existing audit safety transaction or configuration records

5 Consent and safety

Bound treats safety as a core service function Consent based features are designed to default off until a user enables the relevant choice Users may revoke consent disable eligible interactions or block other users Safety reports may be reviewed by authorised Bound Safety Team members and relevant server staff depending on the feature and report destination

Safety controls reduce risk but cannot replace Discord tools emergency services or responsible server moderation If someone is in immediate danger contact local emergency services and use Discord reporting and blocking tools

6 How information is shared

We share information only as needed with Discord hosting database authentication deployment and payment or subscription providers that support the service Information may also be shown to authorised server administrators moderators safety reviewers or ticket staff when the relevant feature requires it

We may disclose information when required by law to protect rights or safety investigate abuse or complete a business transfer We do not sell personal data

7 Security and encryption

Bound uses HTTPS and TLS to encrypt supported data while it travels between your browser our services Discord and our service providers Stored database and hosting data is protected using the at rest security and encryption controls provided by our infrastructure providers Access keys and privileged credentials are kept in server side environments and are not intentionally placed in public browser code

Access is limited through authentication permission checks service roles row level security and operational controls where applicable No online service is perfectly secure Bound is not end to end encrypted and ordinary Discord content remains subject to Discord server permissions and Discord policies

8 Retention

We keep information for as long as needed to provide the feature maintain security resolve disputes meet legal obligations and enforce agreements Retention varies by record Account preferences and active configurations may remain while the service is used Transaction audit moderation verification safety and subscription records may be retained longer where integrity accountability or abuse prevention requires them

Temporary sessions caches and expired interaction state are removed or expire on shorter schedules Backups may retain deleted information for a limited recovery period before being overwritten

9 Your choices and rights

You may use available bot or dashboard controls to change consent privacy notifications blocks and server features You may leave a server remove Bound revoke Discord OAuth access or request access correction or deletion of eligible personal data through Bound Society support

Some records may be retained when required for security legal compliance fraud prevention transaction integrity or the rights and safety of others We will verify the requester before fulfilling sensitive requests Server administrators control their own Discord server content and should be contacted for server managed records

10 Children and age restricted features

Bound is not directed to children under the minimum age required by Discord Users must satisfy Discord age requirements Age restricted or adult roleplay features may only be used by adults in appropriately age gated Discord spaces where required Server owners remain responsible for suitable access controls and lawful community operation

11 International processing and changes

Service providers may process information in countries other than yours and apply their own legal safeguards We may update this policy when features practices or laws change The effective date above will be changed and material updates may also be announced through Bound or Bound Society

12 Contact

For privacy questions or requests email goatedkillr@gmail.com or open a support ticket in Bound Society Include your Discord user ID and enough detail to locate the relevant records but never send passwords tokens identity documents or payment card details
